## Còn thiếu trước bàn giao

1. Ảnh màn **Tài khoản chờ duyệt** (`/users/pending`).
2. Ảnh màn **Phân quyền** (`/users/permissions`).
3. Công thức lương / hoa hồng: màn hình chỉ hiện kết quả.
4. Email “Đã gửi” có tới hộp thư khách thật hay chỉ ghi trên CRM.
